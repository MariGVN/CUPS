# CUPS
# Aplicación de búsqueda y análisis de CUPS

## Descripción

La aplicación permite realizar la búsqueda y el análisis de CUPS contenidos en múltiples archivos Excel de forma automática. Además, facilita la detección de patrones compartidos y la generación de informes en formatos Excel y Word.

## Requisitos

- Sistema operativo Windows.
- No requiere instalación de Python.
- No requiere conexión a Internet para su funcionamiento.

## Instalación

1. Descargar la carpeta **AppCUPS**.
2. Descomprimir el archivo en la ubicación deseada.
3. Mantener la estructura original de carpetas.
4. Ejecutar **app.exe**.

## Uso

### Carga de archivos

1. Seleccionar uno o varios archivos Excel.
2. Pulsar **Subir archivo**.
3. Los archivos quedarán disponibles para su análisis.

### Búsqueda individual

1. Introducir el CUPS deseado.
2. Pulsar **Buscar**.
3. Consultar los resultados obtenidos.
4. Si se desea, exportar los resultados a Excel.

### Análisis múltiple

1. Acceder a la sección **Análisis**.
2. Introducir un CUPS por cada línea.
3. Ejecutar el análisis.
4. Revisar el resumen generado.

### Detección de patrones

1. Acceder a la sección **Detección de patrones**.
2. Revisar los patrones comunes detectados entre los CUPS analizados.
3. Exportar el informe en formato Excel o Word si es necesario.

## Archivos generados

La aplicación permite generar:

- Informe de análisis en formato Excel.
- Informe de detección de patrones en formato Word.
- Informe de búsqueda individual en formato Excel.

## Observaciones

- Los archivos cargados se almacenan temporalmente en la carpeta **uploads**.
- Los informes generados se guardan automáticamente en la carpeta donde se encuentra la aplicación.
- Cada usuario trabaja con una copia independiente de la aplicación y sus datos no se comparten con otros usuarios.
